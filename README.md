## Descripción

Este repositorio contiene la solución de la Guía Práctica 1 sobre Programación Orientada a Objetos (POO) en C#. Los ejercicios demuestran los conceptos de abstracción, encapsulación, herencia y polimorfismo.

## Ejercicios

1. **Abstracción de datos**: clase `CuentaBancaria` con saldo privado y operaciones controladas.
2. **Encapsulación**: clase `Empleado` con propiedades y validación de datos.
3. **Herencia simple**: clases `Vehiculo` y `Coche`.
4. **Polimorfismo**: clases `Animal`, `Perro` y `Gato` con sobrescritura de métodos.
5. **Herencia multinivel**: jerarquía `Animal -> Mamifero -> Perro`.

## Requisitos

- .NET 8 SDK o una versión compatible.
- Visual Studio, Visual Studio Code, Rider o cualquier editor con soporte para C#.

## Ejecución

Cada ejercicio es un proyecto de consola independiente. Para ejecutar uno:

```bash
cd Ejercicio1_Abstraccion
dotnet run
```

Cambie la carpeta por el ejercicio que desee probar.

## Organización

Cada carpeta contiene su archivo `.csproj`, las clases necesarias y un `Program.cs` que demuestra el funcionamiento solicitado en la guía.
